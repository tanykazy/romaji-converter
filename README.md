# romaji-converter

ひらがな・カタカナをローマ字に変換するJavaScriptライブラリです。
内閣告示「ローマ字のつづり方」を最優先とし、内閣告示でカバーできない現代的な外来音（「ヴァ」「ティ」など）については外務省「ヘボン式ローマ字綴方表」（パスポート規格）を用いてフォールバックするハイブリッドな仕様になっています。

## 特徴

- **内閣告示ルール優先**: 「ローマ字のつづり方」本表（標準ルール）をベースに変換します。
- **ヘボン式フォールバック**: 内閣告示に存在しない外来音（「ウィ」「ジェ」「ディ」など）は自動的にヘボン式表記に変換します。
- **撥音（ン）の処理**:
  - B, M, P の前でも内閣告示に基づき `n` となります（例：`シンブン` → `shinbun`）。
  - 母音または `y` の前にある撥音は、アポストロフィ `'` で区切られます（例：`シンアイ` → `shin'ai`、`トンヤ` → `ton'ya`）。
- **促音（ッ）の処理**:
  - 次の文字の子音を重ねて表記します。
  - CHの前でも内閣告示に基づき `c` を重ねて `cch` になります（例：`マッチャ` → `maccha`）。
- **長音（ー）の処理**:
  - パスポート表記のように省略せず、直前の母音を繰り返します（例：`スーパー` → `suupaa`）。
- **ひらがな・カタカナ両対応**: ひらがなは内部で自動的にカタカナに変換して処理されます。記号やアルファベットなどはそのまま出力されます。

## 使用方法

### 1. クラスのインポートとインスタンス化

`RomajiConverter.js` をプロジェクトにインポートし、インスタンスを作成して `convert` メソッドを呼び出します。

```javascript
// モジュールのインポート（必要に応じて適切なインポート形式を使用してください）
// 例: const RomajiConverter = require('./RomajiConverter');
// または直接 script タグ等で読み込む

const converter = new RomajiConverter();

// 変換の実行
const result = converter.convert("こんにちは");
console.log(result); // "konnichiha"
```

### 2. 変換例

#### 内閣告示ルール (直音・拗音)
- `アイウエオ` → `aiueo`
- `キャキュキョ` → `kyakyukyo`

#### 撥音（ン）の処理
- `シンブン` → `shinbun` (※ `m` ではなく `n`)
- `タンイ` → `tan'i` (※ アポストロフィでの区切り)
- `トンヤ` → `ton'ya`

#### 促音（ッ）の処理
- `マッチャ` → `maccha` (※ `matcha` ではなく `maccha`)
- `ザッシ` → `zasshi`

#### 長音（ー）の処理
- `コーヒー` → `koohii` (※ 直前母音の繰り返し)
- `スーパー` → `suupaa`

#### パスポート表記（フォールバック）
- `ヴァイオリン` → `baiorin` (`ヴァ` → `ba`)
- `パーティ` → `paatei` (`ティ` → `tei`)
- `ウィキペディア` → `uikipedia` (`ウィ` → `ui`, `ディ` → `dei`)
